# Объект хандалтат программчлал
**Лабораторийн ажил хийх заавар**

1. **Зөвхөн өөрийн оноогдсон фолдерт өөрчлөлт оруулна.**
2. **Хувьсагч, функц, класс, struct зэргийг англи үгээр тодорхойлно.** Нэр нь утга санаагаа бүрэн илэрхийлсэн, тодорхой байх ёстой.
3. **Бичиглэлийн стандарт :**
    * **Классын нэр:** `PascalCase`
    * **Классын метод болон функцүүд:** `camelCase`
    * **Local хувьсагчид:** `camelCase`
    * **Global хувьсагчид:** `STREAMING_SNAKE` (Жишээ нь: `GLOBAL_VARIABLE_NAME`)
4. **Фолдер болон файлын нэр:** `camelCase` хэлбэрээр бичнэ.
5. **Тайлан болон илтгэлийг `report` фолдероос авна.** 
6. **Хөрвүүлэлт:** `make` команд ашиглан лабораторийн ажлыг машины код руу хөрвүүлж нэгтгэнэ.
7. **Тайлан болон үзүүлэнд кодыг оруулахдаа vsCode ийн theme ийг light2026 болгож copy paste хийх байдлаар оруулна.**
